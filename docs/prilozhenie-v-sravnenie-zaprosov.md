# Приложение В. Сравнение простого запроса и специализированного промпта

Приложение дополняет раздел 2.4. Здесь приведены полная таблица сравнения и иллюстративные фрагменты ответов на одном и том же входе (датасет Spector, `statsmodels.Logit` + метрики sklearn).

## В.1. Вход эксперимента (общий для обоих запросов)

Датасет: Spector & Mazzeo, n = 32; train/test 70/30, stratify, random_state=42 (train = 22, test = 10).
Признаки: GPA, TUCE, PSI; цель: GRADE (0/1).

statsmodels.Logit (train): Pseudo R² = 0.2894, LLR p-value = 0.03938;
const = −8.6592 (p = 0.077); GPA = 1.3938 (p = 0.268); TUCE = 0.0972 (p = 0.536); PSI = 2.5412 (p = 0.046).

Тест (порог 0.5): Accuracy = 0.80, Precision = 1.00, Recall = 0.33, F1 = 0.50, ROC-AUC ≈ 0.90;
confusion matrix [[TN FP],[FN TP]] = [[7 0],[2 1]].

## В.2. Формулировки запросов

**Простой запрос:**

```
Интерпретируй логистическую регрессию по результатам ниже.
[блок данных из В.1]
```

**Специализированный промпт** (сокращённо; полный текст — в Приложении А, тип «интерпретация результатов»):

```
Ты — аналитик данных. Я дам результаты логистической регрессии...
Интерпретируй модель по шагам:
1) что предсказывает модель;
2) влияние признаков (знак, сила, значимость);
3) odds ratio для ключевых коэффициентов;
4) смысл метрик и ошибок FP/FN;
5) итоговое качество и ограничения;
6) 3–5 рекомендаций по улучшению.
[блок данных из В.1]
```

## В.3. Подробная таблица сравнения

| Критерий / аспект | Простой запрос (типичный ответ) | Специализированный промпт (типичный ответ) |
|-------------------|----------------------------------|--------------------------------------------|
| Роль и структура | Свободный текст без фиксированных блоков | Нумерованные шаги по инструкции |
| Интерпретация коэффициента | «PSI > 0 — участие в программе повышает вероятность улучшения оценки» | То же + «при прочих равных» + OR(PSI) = exp(2.5412) ≈ 12.7 (шансы выше примерно в 13 раз) |
| Odds ratio | Часто отсутствует или подменяется «вероятностью» | Явно: OR = exp(β), смысл в терминах шансов |
| GPA / TUCE | Могут быть названы «важными» из‑за знака | Указана незначимость (p > 0.05), эффект ненадёжен |
| Accuracy = 0.80 | «Модель хорошая / приемлемая» | Сравнение с baseline ≈ 0.70 (7 из 10 — класс 0); recall = 0.33 — модель пропускает 2 из 3 положительных |
| Confusion matrix | Часто не разбирается | TN=7, FP=0, FN=2, TP=1: ложных тревог нет, но много пропусков (FN) |
| Ограничения | Слабо или отсутствуют | n = 32, test = 10, один split, нет CV; метрики хрупки |
| Рекомендации | Общие («собрать больше данных») | Конкретнее: порог ≠ 0.5, больше данных, проверка устойчивости, масштабирование |

## В.4. Типичные ошибки простого запроса и как их закрывает промпт

| Ошибка простого запроса | Как устраняет специализированный промпт |
|-------------------------|------------------------------------------|
| Путает вероятность и шансы | Явное требование odds ratio / exp(coef) |
| Нет формулировки «при прочих равных» | Пункт про интерпретацию признаков при фиксированных остальных |
| Хвалит Accuracy при дисбалансе / малом тесте | Требование разобрать CM, precision/recall, ограничения |
| Значимость игнорируется | Требование смотреть p-value |
| Нет ограничений исследования | Отдельный блок «качество и ограничения» |
| Смешение стилей (разговорный + «научный») | Отдельные типы промптов (академический / бизнес / рецензия) |

## В.5. Иллюстративные фрагменты (смысловые)

*Фрагмент в духе простого запроса:*  
«Коэффициент PSI положительный, значит программа помогает. Accuracy 0.80 — модель работает хорошо. GPA тоже повышает вероятность улучшения оценки.»

*Фрагмент в духе специализированного промпта:*  
«При прочих равных участие в программе PSI связано с ростом шансов улучшения оценки примерно в OR = exp(2.54) ≈ 12.7 раза (p = 0.046). GPA и TUCE имеют положительный знак, но незначимы на 5%. Accuracy = 0.80 при baseline ≈ 0.70; precision = 1.00 и recall = 0.33 (FN = 2) — модель осторожна к ложным срабатываниям, но пропускает положительные случаи. Выводы ограничены малым n и одним split.»

Фрагменты приведены как обобщение типичных ответов апробации; полные прогоны специализированных промптов описаны в разделах 2.2–2.3 и Приложении А.
